How to read these measures

VADER classifies apparent comment tone. The cutoff changes which scores count as neutral. Theme counts represent comments that matched specific phrases. A comment can match several phrases or none. Comments per 1,000 views uses the lifetime statistics, while the analyzed comments are recent, accessible top-level posts. The median engagement rate was 5.55 comments per 1,000 views.
